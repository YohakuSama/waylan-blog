## 保持明确分工

- 首页：认识作者与博客主题，开始阅读，找到订阅方式。
- 内容：按类型、主题、标签、关键词与时间排序筛选；支持详细/紧凑显示。
- 归档：完整年月索引，使用紧凑的日期与标题列表，不增加重复筛选面板。
- 项目：真实项目状态、技术栈及实际存在的仓库/演示；适用统一的三端图文顺序。
- 关于：完整介绍、写作方式、联系方式与数据说明。
- 阅读：文章元信息、正文、章节目录、相邻与延伸阅读，以及已有的收藏、分享、划线和讨论。

保留字标、几何配图、网格波纹、两种主题和既有内容，不更换框架、不制造无内容的分类，也不添加不真实的作者履历、订阅表单或文章数据。

## 验证方式

`npm run check` 核对类型、构建、预渲染、离线产物和交互回归；仓库既有 Chromium 工作流继续执行 264 组页面/宽度/外观组合，并补上实际阅读顺序、入口可见性、密度恢复、目录焦点和短视口边界的检查。新截图与几何数据在对应 PR 的 `waylan-viewport-smoke` 附件中。

当前执行环境缺少本地预览守护进程，不能声称完成本地浏览器预览。视觉复核使用 CI 返回的截图；模拟视口仍不能替代 iOS、Android、iPadOS 真机的字体、系统工具栏和长按选择检查。
