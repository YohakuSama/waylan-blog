# 三端布局与页面状态约定

设计依据、参考站点和页面分工见 [DESIGN_RESEARCH.md](DESIGN_RESEARCH.md)。本文件记录当前实现。

## 导航与工具

目的地固定为「首页 / 内容 / 归档 / 项目 / 关于」。项目使用已有 `/projects` 页面，项目阅读页也选中项目入口；文章阅读页选中内容入口。搜索、阅读清单、通知与设置属于独立工具组，不与目的地混排。

| 宽度 | 页眉 | 正文与辅助栏 |
| --- | --- | --- |
| ≥1120px | 68px 单行，品牌、五个目的地与工具分组（中等屏宽搜索收为图标） | 首页最新内容、归档年月索引、关于正文复用相同的主栏与 276px 辅助栏；内容和项目页共用 960px 无侧栏索引 |
| 861–1119px | 单行，搜索收为图标 | 首页主题快捷入口先于最新内容，项目/热门辅助区在文章列表后双列排列；其他索引页保持单列居中 |
| 768–860px | 60px 品牌/工具行 + 44px 常驻目的地行 | 图文横排，首页辅助栏下沉；内容页仅展示正文与筛选器 |
| ≤767px | 同上，五个目的地均可直接点击 | 首页正文单列、隐藏整段桌面辅助栏，主题快捷入口仍可用；内容页使用原生类型选择框和紧凑封面 |
| ≤480px | 品牌在剩余列宽内缩放，四个工具保持 44px 点击区域 | 完整显示标题，摘要最多两行 |

两个主题共用尺寸、导航顺序与阅读字号；主题负责配色、字体风格与装饰。手机主导航始终可见，不使用展开菜单。阅读页只压缩为单行页眉，不改变与首页首行的品牌左边界和全站工具右边界。

## 首页与内容页

- 首页固定最新顺序、详细文字与六条预览，完全不读取内容页的密度偏好；不会出现排序、类型或主题筛选控件。侧栏下沉时仅增加一个「浏览主题」直达入口，而不是重复完整筛选器。
- 帖子卡片复用同一个尾部操作组：稍后再读书签与文章跳转箭头位于同一行、同一高度，首页/内容/项目与紧凑列表一致；手机不另开占宽箭头列。真实帖子标题自然换行，列表摘要仍允许预览截行；侧栏的热门和近期更新标题不得强制单行省略。
- 首篇标题比后续条目突出。电脑首篇可有配图；手机首页不显示大封面，保留标题、摘要与最多两个标签。后续条目减少重复标签、技术栈和统计。
- 介绍只交代博客身份和写作范围；网格装饰在窄屏隐藏，手机进一步收紧纵向留白，继续阅读独立成行。文章区的「全部内容」与底部入口连接到完整内容页。
- 首页桌面把介绍区提升到整个页面宽度，最新内容和小组件在其下并排；小组件仅保留写作主题、真实项目和有真实浏览量时出现的热门阅读，不重复收录阅读提示。≤1119px 主题入口移至文章前、辅助区移动到文章后；≤767px 不堆叠桌面侧栏，仅保留文章前主题入口。侧栏分区标题热区至少 44px。
- 内容页筛选器采用与文章列表一致的无卡片背景、左侧起点与分隔线，避免一个独立的大圆角面板破坏索引节奏；集中管理类型、主题、标签、关键词、排序和「图文 / 列表」。≤767px 时类型分类以单个原生下拉框呈现，平板和桌面保留类型按钮；标签点击会保留当前类型、主题、关键词和排序条件，筛选中可用「清除筛选」归零；显示偏好在该页保存，排序与筛选以 URL 为准。首页不继承这些状态。
- 关于页仅保留一份完整写作范围说明（来自 about.md），桌面将已有技术实现与站点数据放入右侧信息栏，与首页的辅助栏共享宽度和左侧分隔线；≤1119px 时资料回到正文后方、平板双列/手机纵列，不新增重复导航或内容。正文自身仍限制 720px 行宽。混合内容数以「条」计，社交链接至少 44px。
- 归档保留完整年月索引与 16 周真实发布热力图，热力图以最新内容日期为终点，不冒充今日统计；≥1120px 时年月索引与首页主栏同宽、热力图放入右侧辅助栏而非占据整行，年份索引直接开始；≤1119px 时优先呈现年月记录，热力图作为补充信息自然排列在时间索引之后；平板内部说明与图并排，手机则上下排列，DOM 与视觉阅读顺序一致。记录行的日期、类型与标题对齐，年份和主题入口触控高度至少 44px。
- 项目页优先呈现状态、技术栈、实际存在的仓库/演示入口，不叠加全站通用导航侧栏；技术栈是次级纯文字信息，可点击标签保留胶囊外观和独立导航角色，避免两组相似标签重复争抢视觉层级；项目缩略图仅用于较宽屏幕，≤1040px 保留正文里的技术栈及可点击标签，不因隐藏缩略图丢失信息。手机标签最小 40px，外链最小 44px。
- 首页、内容、归档、项目、关于五个一级页面统一使用最大 1140px 的居中外层框架，标题、桌面页眉品牌和页脚信息共享水平起点。内容页与项目页采用相同的 960px 无侧栏索引；首页、归档及关于页面在 ≥1120px 采用共用的 820px 主栏 + 44px 间隔 + 276px 信息栏，关于正文文字行宽单独限制到 720px。窄屏回归单列后不出现隐藏数据或水平滚动。首页介绍区独占整行，随后进入内容与桌面辅助栏。RSS 和关于入口可从顶部导航或页脚访问；旧的 type=all 参数继续兼容。

## 阅读与浮层

≤1040px 时阅读目录通过按钮展开，打开后进入目录焦点；选择章节后进入相应正文标题；Escape 或关闭按钮恢复触发按钮焦点，点击外部和回到桌面断点时关闭。面板尺寸根据当前页眉高度、视口和安全区计算。

通知入口常驻：加载、关闭服务、失败和重试都在面板内说明；窄屏通知面板固定在视口内。表格、代码允许局部滚动，整个页面不产生横向滚动。减少动效模式直接显示最终布局。

## 验证

`npm run check` 覆盖类型检查、构建、预渲染、离线产物和交互回归。`scripts/visual-smoke.mjs` 覆盖八类页面（含隐私和 404）、18 个宽度、四种外观共 576 组；常规 PR 包含 601px 与 1025px 两处边界、共 288 组，并直接模拟有 13% 阅读记录、内容页已保存列表偏好的访问状态。

关键流程为「内容改成由旧到新 + 列表 → 首页仍为最新顺序与固定布局 → 内容仍保留自身偏好」。另外回归「旧排序 → 点击标签保留排序 → 清除筛选归零」，及 700/701/767/768px 的选择器断点和移动标签热区。同时测量五个常驻导航、工具分区、首屏内容密度、目录/通知边界和主题间位置。截图与几何数据在对应 Actions 的 `waylan-qa-evidence` 附件中。新增核对公共页脚和 404 导航的 44px 目标、搜索推荐词触控尺寸与列表框语义；无障碍扫描含搜索/设置/书签/通知打开态及模拟登录后台。设备模拟不代表 iOS、iPadOS 和 Android 真机触控验收。

## 页面与控件一致性补充（2026-11-07）

- 隐私页接入与五个一级页面相同的 1140px 居中外层，标题、英文栏目与正文从共同左边界开始；隐私正文仍为最大 720px。
- 设置面板的颜色模式与正文字号共用 44px 分段选项，不再由字号组独立覆盖高度。
- 手机宽度或粗指针设备上，首页、内容与项目共用的标签链接目标至少 40px；覆盖触屏平板，同时保留 320px 首页标签的紧凑横向内边距。桌面普通指针保留原有标签密度。
- 手机或粗指针设备上的图文/列表切换按钮为 44px 高，桌面普通指针保留 40px。
- 卡片元信息不再预留已移到尾部的收藏按钮高度，最小高度与 24px 事实行一致，长内容继续自然换行；尾部间隔使用 8px，触屏标签行距使用 4px，保留原有首屏内容密度。
- 既有 576 组浏览器矩阵新增隐私页的跨页版心对齐比较、全部列表标签的触屏尺寸与操作区不重叠检查、列表切换的 44px 触屏检查，以及设置分段选项的同高检查；新增设置尺寸记录随视觉附件保存。验证结果以对应 PR 提交的实际 CI 为准。

### 2026-11-07 反馈后的二次校正

上一轮仅以“960px 同宽”和移动热力图通过几何测试作为充分标准，但实际截图显示热力图被悬置在列表上方，破坏首屏信息层级。本次调整的设计依据为：相同的内容/辅助栏关系可以复用；引用、筛选和时间轴作为不同内容类型仍允许不同表达。任何涉及栅格的验收都要检查模块与相邻模块的空间关系，而不仅是单独宽度。

- 桌面：页眉品牌与正文栏目左边界对齐；首页、归档、关于的右栏位置一致；归档年份靠近引言而不是被热力图整体推下；内容页筛选与列表从同一左边界开始。
- 平板与手机：关于信息、归档热力图均留在页面阅读顺序里；不照搬桌面右栏；筛选可用、触控目标尺寸和两种皮肤深浅模式位置不漂移。
- 风险与边界：浏览器矩阵检查几何、交互与回归，不能代替人工完整视觉审美验收或真实设备屏幕核对；当前没有改变品牌素材、站点数据、后端或内容顺序。
