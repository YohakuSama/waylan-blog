# 双主题与三端布局约定

本次沿用现有首页、内容、归档、项目、关于和阅读器，不更换框架或内容结构。

## 一套布局，两种表现

布局尺寸由 `src/styles/site.css` 和阅读器的 `src/styles.css` 负责。`src/styles/skins.css` 负责配色、字体风格、圆角、边框和装饰。新增功能应先改共用组件，再同时检查杂志与终端的浅色、深色四种组合。

- 顶栏始终使用「首页 / 内容 / 归档 / 关于」。终端提示符只作装饰，不替换中文名称。
- 导航槽位、搜索、阅读清单、阅读设置在切换主题时保持位置和尺寸。通知入口常驻在阅读清单与阅读设置之间；加载中、服务未开启或读取失败都在面板内展示状态，并提供重试。窄屏消息面板固定在视口内。
- 首页先显示「Waylan 的个人博客」、原有主标题与站点介绍首句，再提供内容、关于和 RSS 三个文字入口。必要信息始终处于主内容流，不能依赖侧栏在窄屏上的位置。
- 文章区保留可见的「最新内容」标题，下方用普通链接提供已有内容的主题入口；这不是第二套筛选器。完整类型、主题和排序控制仍集中在内容页。
- 列表密度按钮置于结果行，在所有宽度都可操作；读者在电脑上选择紧凑列表后，手机也必须能够恢复详细列表。
- 收藏始终位于每张卡片元信息行的右上角，不依赖悬停显示。回到顶部位于右下角并避开系统安全区。
- 两个主题使用相同阅读字号档位；等宽风格不再偷偷减小正文字号。

## 响应式布局

| 宽度 | 结构 |
| --- | --- |
| ≥1280px | 内容与侧栏并列，图片列随可用宽度伸缩 |
| 861–1279px | 顶栏导航保留，搜索收成图标；侧栏移至正文下方，分两列 |
| 768–860px | 导航折叠成菜单；正文保持横向图文布局；侧栏仍为两列 |
| ≤767px | 图文卡片先显示类型、日期、标题与摘要，再显示配图；六种类型以 3×2 展示，侧栏顺序流动 |
| ≤480px | 终端品牌只保留站名，两个主题的品牌均限制在可用列宽内，保证 320px 窄屏仍容纳全部顶栏工具 |

减少动效模式下，首屏直接处于最终位置，不保留入场动画的延迟位移。

菜单打开后聚焦第一个入口，Escape 关闭并返回触发按钮；跨过桌面断点时清理展开状态。移动端菜单为每个入口显示用途说明。分类与排序继续集中在内容页。归档采用单列年月列表，移除重复统计卡片和说明侧栏；只有多个年份时才显示简洁的年份跳转链接。

阅读目录在 ≤1040px 时由按钮展开，打开后聚焦目录入口，Escape 或关闭按钮恢复触发按钮焦点；点击外部或跨回桌面断点时关闭。面板宽高受视口与安全区约束，低高度横屏也不能截断目录。短篇没有章节时，入口明确写「查看阅读进度」。

## 参考方式

- [Overreacted](https://overreacted.io/)：文章标题、日期、摘要形成清楚的列表层级。
- [Josh W. Comeau](https://www.joshwcomeau.com/)：文章列表与分类入口分工明确。
- [阮一峰的网络日志](https://www.ruanyifeng.com/blog/)：最新文章与时间归档各有用途。
- [Anthony Fu](https://antfu.me/)：少量清楚的页面入口，项目作为独立目的地。

借鉴信息组织方式，保留 Waylan 原有字标、网格波纹、配图与两种主题。

## 回归检查

`npm run check` 执行类型检查、正式构建、预渲染、离线构建及现有功能测试。仓库 CI 在此之后执行 `scripts/visual-smoke.mjs`，覆盖六类页面、11 种宽度、两种皮肤和两种明暗模式，共 264 组；同时比较主题切换前后的导航与按钮坐标，检查横向溢出、侧栏关系、收藏位置、阅读字号及菜单焦点。新增核对首页身份、可见分区标题、关于/RSS/主题入口、手机标题先于配图、密度偏好持久化后的恢复操作，以及 480px 高度下的目录边界和焦点。四个常驻工具按钮均纳入坐标比较；另外用 16 组通知开启及读取失败状态检查面板边界，并验证失败后重试。

浏览器截图和实际几何值存入该次 Actions 的 `waylan-viewport-smoke` 附件。设备模拟不能代替 iOS / Android / iPadOS 真机的触控与浏览器工具栏检查。
