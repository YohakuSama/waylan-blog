# 三端布局与页面状态约定

设计依据、参考站点和页面分工见 [DESIGN_RESEARCH.md](DESIGN_RESEARCH.md)。本文件记录当前实现。

## 导航与工具

目的地固定为「首页 / 内容 / 归档 / 项目 / 关于」。项目使用已有 `/projects` 页面，项目阅读页也选中项目入口；文章阅读页选中内容入口。搜索、阅读清单、通知与设置属于独立工具组，不与目的地混排。

| 宽度 | 页眉 | 正文与辅助栏 |
| --- | --- | --- |
| ≥1120px | 68px 单行，品牌、五个目的地与工具分组（中等屏宽搜索收为图标） | 主列与辅助栏并排 |
| 861–1119px | 单行，搜索收为图标 | 首页辅助栏下沉、简介提供主题直达入口；内容页省去重复侧栏 |
| 768–860px | 60px 品牌/工具行 + 44px 常驻目的地行 | 图文横排，首页辅助栏下沉；内容页仅展示正文与筛选器 |
| ≤767px | 同上，五个目的地均可直接点击 | 首页全文字条目；内容页类型使用原生选择框、图文模式使用较短封面且省去重复侧栏 |
| ≤480px | 品牌在剩余列宽内缩放，四个工具保持 44px 点击区域 | 完整显示标题，摘要最多两行 |

两个主题共用尺寸、导航顺序与阅读字号；主题负责配色、字体风格与装饰。手机主导航始终可见，不使用展开菜单。

## 首页与内容页

- 首页固定最新顺序、详细文字与六条预览，完全不读取内容页的密度偏好；不会出现排序、类型或主题筛选控件。侧栏下沉时仅增加一个「浏览主题」直达入口，而不是重复完整筛选器。
- 首篇标题比后续条目突出。电脑首篇可有配图；手机首页不显示大封面，保留标题、摘要与最多两个标签。后续条目减少重复标签、技术栈和统计。
- 介绍只交代博客身份和写作范围；网格装饰在窄屏隐藏，手机进一步收紧纵向留白，继续阅读独立成行。文章区的「全部内容」与底部入口连接到完整内容页。
- 首页辅助栏只提供写作主题、真实项目和阅读提示，避免重复作者介绍、近期文章列表与全站导航。侧栏分区标题整行可点击且热区高度至少 44px。
- 内容页集中管理类型、主题、标签、关键词、排序和「图文 / 列表」。≤767px 时类型分类以单个原生下拉框呈现，平板和桌面保留类型按钮；标签点击会保留当前类型、主题、关键词和排序条件，筛选中可用「清除筛选」归零；显示偏好在该页保存，排序与筛选以 URL 为准。首页不继承这些状态。
- 关于页在 ≥1120px 保留阅读导览，窄屏直接以正文、写作主题、技术说明与「浏览全部内容」收尾，不在文末叠加完整侧栏。站点数据是静态标题，混合内容数以「条」计，关于页社交链接至少 44px；三个独立说明区使用二级标题。
- 归档继续使用完整年月索引，不重复内容页的筛选器；记录行使用轻量类型标识区分文章、笔记、想法、日志与项目，统计以「条记录」描述混合内容，年份导航与主题入口保持至少 44px 点击高度。项目页显示项目状态、技术栈与实际存在的外链；≥1120px 仅保留简洁的主题与站内导航侧栏，窄屏省去重复侧栏。项目页移动端标签最小 40px、未来仓库与演示入口最小 44px；未公开仓库时缩略图明确标为「项目」而非伪仓库。主题链接使用 /feed?topic=<id>，保留旧的 type=all 参数兼容。内容页侧栏仅保留在 ≥1120px；侧栏标题没有独立目标时不再伪装成链接。RSS 和关于入口可从站点页脚和全站导航访问。

## 阅读与浮层

≤1040px 时阅读目录通过按钮展开，打开后进入目录焦点；选择章节后进入相应正文标题；Escape 或关闭按钮恢复触发按钮焦点，点击外部和回到桌面断点时关闭。面板尺寸根据当前页眉高度、视口和安全区计算。

通知入口常驻：加载、关闭服务、失败和重试都在面板内说明；窄屏通知面板固定在视口内。表格、代码允许局部滚动，整个页面不产生横向滚动。减少动效模式直接显示最终布局。

## 验证

`npm run check` 覆盖类型检查、构建、预渲染、离线产物和交互回归。`scripts/visual-smoke.mjs` 覆盖六类页面、16 个宽度、四种外观共 384 组，并直接模拟有 13% 阅读记录、内容页已保存列表偏好的访问状态。

关键流程为「内容改成由旧到新 + 列表 → 首页仍为最新顺序与固定布局 → 内容仍保留自身偏好」。另外回归「旧排序 → 点击标签保留排序 → 清除筛选归零」，及 700/701/767/768px 的选择器断点和移动标签热区。同时测量五个常驻导航、工具分区、首屏内容密度、目录/通知边界和主题间位置。截图与几何数据在对应 Actions 的 `waylan-viewport-smoke` 附件中。设备模拟不代表 iOS、iPadOS 和 Android 真机触控验收。
