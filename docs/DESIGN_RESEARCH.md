# 布局调研与设计约束

本轮目标：三端先突出可阅读的内容，明确首页、内容检索、时间归档、项目成果与作者介绍的分工；内容页的显示偏好不能改变首页。

## 一手参考与取舍

| 来源 | 实际观察 | 对 Waylan 的应用 |
| --- | --- | --- |
| [Linear Now](https://linear.app/now) | 全站导航、内容栏目、搜索与文章卡片各处于独立层级；文章标题和摘要组成稳定的扫描单元 | 顶栏区分目的地与工具，筛选留在内容页；不照搬营销站的大幅图片 |
| [Cloudflare Blog](https://blog.cloudflare.com/) | 博客名称与一句定位之后直接进入日期、标题和摘要；分类与账户操作分开 | 缩短首页介绍，明确技术记录定位，让标题先成为阅读入口 |
| [Stripe Blog](https://stripe.com/blog) | 全站产品导航、博客分类、文章信息和订阅用途不同 | 主导航不兼任类型筛选；订阅是次级入口，不与最新文章争夺主按钮 |
| [Overreacted](https://overreacted.io/) | 标题、日期和简短描述连续排列，没有每篇强制的大封面 | 手机首页以文字扫描为主，封面不占用整屏；第一篇与后续条目使用明确字号层级 |
| [Anthony Fu / Posts](https://antfu.me/posts) | Blog、Projects、Talks 是不同目的地，文章按年份、标题与日期组织 | 将已有项目页提升为一级入口，归档专门处理年月索引 |
| [Josh W. Comeau](https://www.joshwcomeau.com/) | Articles and Tutorials 与类别、课程、作者介绍有明确用途 | 保留可见的文章区标题，提供完整摘要与明确阅读入口 |
| [Discourse Meta](https://meta.discourse.org/categories) | 导航、分类/标签与话题列表的操作边界明确，栏目有用途说明 | 顶栏常驻目的地；分类、排序和显示模式在内容列表附近操作 |
| [Hacker News](https://news.ycombinator.com/) | 标题比统计与操作更突出，同屏可迅速浏览多条记录 | 首页减少重复统计、重复标签和大图，辅助数据降级 |
| [开源博客模板](https://github.com/timlrx/tailwind-nextjs-starter-blog) / [antfu.me 源码](https://github.com/antfu/antfu.me) | 成熟博客将首页、文章、项目、标签及阅读页拆分为有清晰职责的页面 | 采用页面边界与可维护的组件分工，沿用本项目现有框架与品牌资产 |

这是基于实际页面的信息结构与关键桌面截图得出的设计判断，不意味着这些站点使用同一种排版，也不把某个品牌的界面原样复制到个人博客。

## 页面分工

| 页面 | 主任务 | 不应串入的状态 |
| --- | --- | --- |
| 首页 | 交代定位，优先展示最新六条内容，提供继续阅读与完整内容入口 | 内容页的图文/列表、筛选与排序 |
| 内容 | 检索全部内容，按类型、主题、标签、关键词筛选和排序 | 首页的首篇强调与六条预览限制 |
| 归档 | 完整年月索引 | 图文卡片与重复类型筛选 |
| 项目 | 查看真实项目、状态、技术栈和外链 | 混在文章页下的导航选中状态 |
| 关于 | 了解作者、写作方向、联系方式与数据说明 | 首页重复的作者介绍卡片 |

顶栏新增的是已有 `/projects` 页的「项目」入口，没有新造栏目内容。手机与窄平板使用工具行和五个目的地的栏目行，避免所有入口藏进同一菜单。工具保持搜索、阅读清单、通知、设置四个入口。

## 三端规则

- 电脑：目的地与工具左右分组；首页第一篇可配图，后续以标题和摘要为主；侧栏用于主题与项目导览。
- 平板：空间不足时将辅助栏移至正文后，主要入口仍在常驻导航；正文保持足够列宽。
- 手机：首页使用完整宽度的文字条目，隐藏装饰画面和大封面；首篇标题更突出，后续条目更紧凑；继续阅读独立成行，长标题截断显示但保留完整可访问名称。
- 内容页：显示模式用「图文 / 列表」文字标注；偏好在该页保留；切回首页时始终恢复首页专用布局与最新顺序。
- 双主题共用布局尺寸与交互，主题只改变字体风格、配色和装饰。

## 验收

除原有构建、离线与功能检查外，浏览器检查直接模拟「内容页改成由旧到新 + 列表 → 返回首页 → 再回内容」：首页必须仍按最新六条显示，内容页保留自己的显示偏好。同时检查 320–1440px 的五个导航入口、工具边界、首屏至少两条内容、13% 继续阅读状态、双主题位置、目录和通知面板。
