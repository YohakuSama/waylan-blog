# Waylan 视觉标识（2.0）

## 头像 / 站标

`src/components/Wordmark.tsx` 的 `Monogram` 是唯一来源，按皮肤切换两套形态，颜色全部取自主题 Token，明暗自动适配：

| 皮肤        | 形态                                                       | 颜色来源                       |
| ----------- | ---------------------------------------------------------- | ------------------------------ |
| 杂志（默认）| 衬线几何 W（三道粗笔 + 细笔 + 衬线），右下角一枚落款圆点   | `--ink` 字形，`--brand` 圆点   |
| 终端        | `>` 提示符 + 等宽 W + 光标块                               | `--ink` 字形，`--hl-prompt` 光标 |

- 悬停个人卡片时圆点微微放大、终端光标开始闪烁；“减少动效”与触屏下保持静止。
- `MONOGRAM_W` 的所有子路径必须保持同一绕向（nonzero 填充），否则粗细笔交叠处会出现镂空。修改几何后请放大到 512px 检查。

## 浏览器图标

- 页面内头像/加载标识保留上文的双皮肤 `Monogram`；小尺寸浏览器标签单独使用更清晰的单线几何 W 和右上角短光标，不将复杂头像硬缩到 16px。
- `public/favicon.svg` 与 `public/avatar.svg` 内容一致（`tests/branding.test.ts` 校验）；浅色系统为深松绿底/暖白字/薄荷绿光标，深色系统自动反转为浅底深字，保持清晰对比。
- `favicon.ico`（16/32）、`favicon-32.png`、`favicon-64.png` 与 `apple-touch-icon.png`（180）由该 SVG 栅格化；更改图形时必须同步这四种回退/触控资源，不能仅替换 SVG。
- `public/theme.js` 在首帧前按皮肤与明暗写入 `meta[name=theme-color]`，移动端地址栏颜色与页面一致。

## 容器与动效

- 杂志：轻圆角纸面容器、衬线标题。终端：直角、虚线分隔、`#` / `##` 前缀。
- 导航不使用 `transform` 位移；页面切换以共享封面和主区域淡入为主，时长不超过 300ms。
- 加载提示统一为页眉底部一条细线（`.site-header::after`），仅在阅读器分块确实需要加载超过 140ms 时出现。
