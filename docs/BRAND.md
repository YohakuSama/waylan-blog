# Waylan 视觉标识（2.0）

## 头像 / 站标

`src/components/Wordmark.tsx` 的 `Monogram` 是唯一来源，按皮肤切换两套形态，颜色全部取自主题 Token，明暗自动适配：

| 皮肤        | 形态                                                       | 颜色来源                       |
| ----------- | ---------------------------------------------------------- | ------------------------------ |
| 杂志（默认）| 衬线几何 W（三道粗笔 + 细笔 + 衬线），右下角一枚落款圆点   | `--ink` 字形，`--brand` 圆点   |
| 终端        | `>` 提示符 + 等宽 W + 光标块                               | `--ink` 字形，`--hl-prompt` 光标 |

- 悬停个人卡片时圆点微微放大、终端光标开始闪烁；“减少动效”与触屏下保持静止。
- `MONOGRAM_W` 的所有子路径必须保持同一绕向（nonzero 填充），否则粗细笔交叠处会出现镂空。修改几何后请放大到 512px 检查。

## 浏览器图标

- 原有页眉 `Waylan` 手写字标与站内双皮肤 `Monogram` 保持不变。浏览器标签不再使用深绿色方形应用图标，而以站内 `MONOGRAM_W` 相同的高对比衬线 W 字形为基础，放大并调整纵横比后，增加一枚低调的朱红落款圆点：透明底 `W.`。
- `public/favicon.svg` 与 `public/avatar.svg` 保持同源；浏览器矢量图标依照系统深浅模式反转墨色，不能依赖站点页面的主题变量。避免增加背景容器、小字和复杂装饰，优先检查 16px 可辨性。
- 32/64px PNG 与 16/32px ICO 是浏览器回退；180px Apple touch 图标使用同一 W.，但加不透明暖纸色背景以适配主屏幕。以上文件必须一起重新导出。
- `index.html` 的图标查询版本号独立于部署文件名，更新时同步递增，避免浏览器长期缓存旧标识。
- `public/theme.js` 在首帧前按皮肤与明暗写入页面 `theme-color`；站内主题颜色与浏览器 UI 外观是不同层级。

## 容器与动效

- 杂志：轻圆角纸面容器、衬线标题。终端：直角、虚线分隔、`#` / `##` 前缀。
- 导航不使用 `transform` 位移；页面切换以共享封面和主区域淡入为主，时长不超过 300ms。
- 加载提示统一为页眉底部一条细线（`.site-header::after`），仅在阅读器分块确实需要加载超过 140ms 时出现。
