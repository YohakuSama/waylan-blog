## 通知恢复时的按钮身份（新增回归）

- [CI #42231538505](https://github.com/YohakuSama/waylan-blog/actions/runs/42231538505) 已成功执行三浏览器启动、构建、通用交互、WCAG、阅读器与多个端侧专项；但在 768px、Terminal 浅色通知失败→恢复状态测试中，原本用于“重试”的按钮被错误复用为“使用 GitHub 登录”，意外跳转 OAuth 路径，视觉矩阵未能完成，不能标记通过。
- 根因：两个条件分支在相同位置渲染同类型的 `<div><button>`，React 允许保留原 DOM 按钮并替换 `onClick`；并发状态更新时，点击动作可能落到新处理函数。使用不同的 `key` 区分重试和登录分支，使旧按钮卸载；不修改登录 API、状态语义、外观或触控目标尺寸。
- 现有视觉脚本已经覆盖不应导航到 OAuth；新增旧按钮必须脱离 DOM 的浏览器断言及静态回归合同。后续以最终提交的实际 CI 为准。
