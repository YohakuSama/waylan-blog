# Waylan 设计系统 · 留有回声的书页

## 设计决策

“窗口”负责进入，“书页”负责阅读，“页边”负责对话。页面像被同一个人长期打理的数字手札。视觉靠留白、细线、字重与可追踪的位置关系建立层次。无横向轮播、无视口锁定的信息流、无 WebGL 常驻背景。

对外站名和作者均为 Waylan，品牌标记按 `docs/BRAND.md` 使用 W 落款徽记与终端提示符两种形态；阅读批注使用独立的声波线条。原创配图由同一套几何静物语言绘制：拱窗、纸张、树影、笔与小径。它们是可编辑的 SVG，社交预览提供 PNG，不依赖第三方图片站。

## Tokens

基础刻度见 `src/styles.css :root`，四种外观的语义颜色见 `src/styles/skins.css`。`--control-border` 专供需识别边界的控件，`--line` 保留为低干扰的内容分隔线。主组件复用变量，不各自创建颜色与运动语言。

## 样式归属与加载顺序（P3 首批）

实际样式只通过 `src/styles/index.ts` 加载，线上和离线预览共用。字体优先，其后按**固定顺序**读取：

```text
src/styles.css                 基础 tokens、阅读器、弹层
src/styles/shell.css           页眉、首页、外壳控件
src/styles/feed.css            信息流基础卡片
src/styles/sidebar.css         侧栏基础结构
src/styles/site.css            索引页、页脚、阅读外壳对齐
src/styles/responsive.css      跨页面屏宽布局与手机卡片
src/styles/skins.css           editorial / terminal 外观差异
src/styles/motion.css          动效与减少动效
src/styles/reader-progress.css 阅读进度条
src/styles/image-viewer.css    图片预览共用结构
src/styles/announcements.css   公告与通知
src/styles/projects.css        仅项目页卡片、比较布局及局部断点
```

一个问题的定位顺序：先找到拥有该 DOM 的组件及其主样式；**只有断点相关才继续读 responsive**，**只有主题差异才继续读 skins**。不能为了快速覆盖而在皮肤文件里新增公共网格/字体几何补丁；有意改变布局时，必须检查此后所有同优先级选择器与媒体查询。原先的 `site.css` 分拆只按顶层完整规则边界切开、保持原声明的级联先后，并删除两组已经被最后手机卡片规则完全覆盖的旧标题声明；其余样式暂不迁移。详细故障定位表见 [ARCHITECTURE.md](ARCHITECTURE.md)，断点契约见 [RESPONSIVE_LAYOUT.md](RESPONSIVE_LAYOUT.md)。

## 运动与空间

共享标题和配图使用稳定 `view-transition-name`，先加载目标阅读模块，再截图转场，确保目的地存在。浏览历史条目有独立 key，回到来源时恢复对应筛选与位置。组件退出取消旧动画，避免重新打开时被旧关闭回调关掉。

偏好减少动效时跳过 View Transitions 和面板动画，CSS 也关闭装饰运动；低核心数设备使用轻量过渡，保留可见反馈；不再提供手动完整／减弱动效预设，由系统辅助功能偏好控制。不会阻止自然页面滚动。

## 首页信息顺序

1. 主区域用简短身份和写作范围介绍本站，窄屏不叠加装饰文字；关于与 RSS 为次级文字入口。≤1119px 时增加「浏览主题」入口，避免下沉侧栏埋藏内容分类。
2. 可见的「最新内容」标题与首篇强调承接六条固定预览；完整筛选和显示偏好只属于内容页。
3. 未完成的阅读记录单独成行；侧栏只补充主题、真实项目与阅读提示。手机首页用文字扫描，不给每篇堆叠大封面和标签。

## 可访问性与响应式

语义导航、主内容跳过链接、可见 focus、可理解的按钮名称、原生对话框和键盘可操作批注。移动端独立安排导航与侧页，不把桌面三栏缩小；表格和代码可局部横向滚动，整个页面与卡片保持正常纵向流。最终对比度、放大 200% 与长按选择仍需真实设备复核。
