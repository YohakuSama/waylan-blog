## 你好，我是 Waylan。

这里是我的个人技术记录空间，不是前端开发教程站，也不以某个职业身份来定义内容。日常遇到的系统问题、软件配置、网络服务、实用工具与新技术，值得研究的我都会动手试一试，再整理成可复现的文章。

### 我怎样写技术实践

一篇实践记录会尽量回答：**为什么要做、在什么环境下做、具体步骤是什么、遇到哪些问题、怎样确认结果**。需要时附上命令、配置、适用版本、回退方式和参考链接。试过但不适用的方案也会说明，避免把个人经验写成通用结论。

### 这里会有哪些内容

- **系统与软件**：Linux、Windows、macOS 的部署、配置和日常使用。
- **网络与服务**：网络排障、远程访问、私有服务与运维经验。
- **工具与开发**：脚本自动化、开发工具、少量与实际需求有关的编程记录。
- **新技术体验**：AI、Web3 等技术的尝试、比较和使用边界。
- **随笔**：不适合写成教程的观察、阅读和思考。

文章可能随实践而更新；发现步骤过时或结论不准确时，会优先修订并标明变化。

**关于本站功能**：外观偏好和私人划线仅保留在当前浏览器；公开评论依赖 GitHub Discussions 与本站服务端，完成部署和关联后即可使用。

### 隐私与数据说明

更新日期：2026 年 11 月 5 日。本节介绍本站源代码实现的数据处理方式；第三方服务自身的处理与保留政策以其公开政策及实际配置为准。

**访问、统计与基础安全。** 本站不投放广告。生产页面包含 Cloudflare Web Analytics 统计脚本，不能将本站描述为“无第三方统计脚本”。脚本是否成功上报、Cloudflare 实际接收的数据项目及保存时间需要以线上配置和第三方政策核实。本站还会在服务端对文章浏览次数进行按日去重：以来源 IP、文章、日期和站点密钥生成哈希标记，不在 D1 保存原始 IP，也不为这个浏览计数设置 Cookie。去重标记有效期不超过约两日，由每日定时任务清理；聚合浏览计数则会继续保留。接口使用短期哈希限流桶；基础网络与安全日志还可能由 Cloudflare 按其服务设置处理。

**GitHub 登录与公开评论。** 评论需经 GitHub 授权，本站会取得 GitHub 账号标识、用户名、头像及公开个人主页；评论正文及公开互动保存在 GitHub Discussions，对外可见。生产配置已显式选择 GitHub App 登录，其授权受 GitHub App 安装与用户权限限制。你可通过 `/api/status` 的 `authProvider` 核实当前实际运行模式。若站长切回旧版 OAuth 兼容模式，登录仍会申请 `public_repo` 权限，范围**不只限于评论**；应以 GitHub 授权页面显示的权限为准。只有完成真实登录和评论写入测试，才能确认 GitHub App 评论权限实际可用。

**登录会话与授权令牌。** 站点的会话 Cookie 采用 HttpOnly、SameSite=Lax、Secure；D1 只保存会话标识的哈希和经 AES-GCM 加密的 GitHub 访问令牌，而不以明文保存令牌。会话最长约 7 天，亦可能因 GitHub 令牌有效期而缩短；主动退出会删除对应服务端会话。GitHub 登录的临时 state、加密 PKCE verifier 和安全返回路径最长有效 10 分钟。过期会话与授权状态由每日定时任务清理，实际清理可能晚于失效时点。

**评论关联与站内通知。** 站点为文章保存 GitHub Discussion 映射、公开批注的定位信息及用于防重复提交的请求记录。防重复提交记录超过 90 天后按定时任务清理；批注与文章关联可能长期保留，直到相关内容被删除或人工处理。启用通知功能时，D1 保存收件人和发言者的 GitHub 用户名、评论标识、通知类型、时间、已读状态及提醒开关；通知记录保留约 180 天并定时清理。通知设置没有统一的自动到期日。私人通知按登录账号隔离，不公开展示。

**浏览器本地数据。** 主题、阅读偏好、阅读清单和私人划线等功能使用浏览器本地存储；清除该网站的浏览器数据可以删除这些本地记录。公开评论和服务端会话不会因为清除本地数据而自动从 GitHub 或 D1 删除。

**第三方与联系。** 网站使用 Cloudflare 提供托管、边缘安全、数据库及可能的网站分析服务，并使用 GitHub 提供登录与公开讨论。有关数据访问、更正或删除的请求，可以从[站长 GitHub 主页](https://github.com/YohakuSama)提供的联系入口提出；请勿在公开讨论中发送身份证件、Cookie、令牌等敏感信息。GitHub Discussions 上的评论可按平台提供的功能编辑或删除；第三方已经处理的资料仍受相应平台的政策约束。本站尚需补充经过确认的**非公开权利请求联系渠道**，在该渠道公布前本说明不应视为完整法律合规验收。
